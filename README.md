# world happiness data analysis
Python analysis of global happiness trends and their economic, social and institutional correlates.

Research Question: How has reported happiness changed across countries and over time, and how is it associated with economic, social, institutional, and emotional factors?

This is 3-person academic project done in December 2025. 
Done by: Laure REYTAN, Sofia JORDAN and Alexia LAZES. 

Python, pandas, NumPy, Matplotlib, statsmodels, and Jupyter Notebook.
Dataset: World Happiness Data 2024

Covered in this project:
Data cleaning and missing-value handling
Descriptive statistics and country comparisons
An exploratory, normalized composite score
Correlation analysis and data visualization
Emotional-balance analysis
Single-factor OLS regression models
Discussion of methodological limitations


The analysis is descriptive and exploratory. Reported correlations and regression coefficients are associations, not causal effects.
